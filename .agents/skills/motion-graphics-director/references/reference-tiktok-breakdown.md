# TikTok motion-language case study

Analysis of a user-supplied 74.17-second 576×1024, 30 FPS reference (TikTok account @galihry.id, video 7696009626147376402). This is evidence-based creative analysis, not permission to copy protected footage.

| Time | Observed beat | Motion principle |
|---|---|---|
| 00–03s | Text hook; outlined and solid typography | Per-phrase kinetic type and contrast |
| 03–04s | Full orange interstitial, rotating mark | Shape/color stinger |
| 04–10s | Claude-like prompt UI and text entry | Typing cursor, interface action |
| 10–13s | Script/sections appear | Progressive content reveal |
| 13–19s | Visual cards: motion graphic/diagram/animation | Staggered layout of elements |
| 19–21s | Code view beside visual | UI components animated independently |
| 21–27s | Recording/timeline/audio editing illustration | REC, playhead, timeline tracks |
| 27–28s | Orange transition | Transition stinger |
| 28–33s | Logo springs into place | Scale pop, overshoot |
| 33–38s | Moving logo and small particles | Particle motion and rotation |
| 38–39s | Diagonal color bands | Full-frame shape wipe |
| 39–48s | IDE → NASKAH → REKAM → VISUAL → EDIT → POSTING diagram | Nodes appear sequentially; SVG connectors draw |
| 49–55s | Data bars 12,18,15,27,34,48 and line trend | Growing bars, line reveal, labels |
| 55–64s | Large kinetic words, palette changes | Animated type hierarchy |
| 64–68s | NASKAH/VISUAL merge toward VIDEO | Object relationships and transform |
| 68–74s | Follow prompt with button state | CTA and animated state change |

The reference **is not a hand-drawn whiteboard animation**. It largely uses fixed camera and animated internal vector/UI objects. Avoid rendering its distinct logo, branding, voices or soundtrack.
